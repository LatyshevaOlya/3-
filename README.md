# Приключения лягушки

Небольшой платформер на HTML, CSS, Canvas и ванильном JavaScript.

## Управление

- ← → или A/D — движение
- Space, W или ↑ — прыжок
- Повторный прыжок в воздухе запрещён
- На телефоне: кнопки ←, → и «Прыжок»

## Цель

Собери 20 светлячков, пройди Болото и Облачное королевство,
затем в Ледяном королевстве столкнись с пингвином, чтобы получить корону.

## Опасности

- Полицейские-бананы и тележка с яблоком
- Падение в воду на болоте
- Вороны
- Жители Облачного королевства
- Сосульки

## Запуск

```bash
npx serve .
```

Открой предложенный сервером адрес, например `http://localhost:3000`.

## Особенности

- Один игровой цикл на `requestAnimationFrame`
- Физика учитывает `dt`, поэтому скорость не зависит от частоты монитора
- Пауза при переходе на другую вкладку
- Рекорд сохраняется в `localStorage`
- Рестарт полностью сбрасывает уровень, предметы и счёт

## Использование нейросети

Игра создана с помощью Perplexity. Использовались промпты:

1. «Создай платформер на Canvas с игроком, гравитацией, платформами и столкновениями».
2. «Добавь предметы, опасности, победу, поражение и счёт».
3. «Добавь паузу, рестарт, сохранение рекорда и мобильные кнопки».
4. «Оформи игру в стиле Adventure Time с лягушкой, светлячками и короной».
